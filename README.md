# Meeting Briefing LWC & Agentforce Integration

## Project Purpose
This project contains a custom Salesforce Lightning Web Component (LWC) and supporting Apex classes designed to assist with meeting briefings and flight management. It demonstrates how to handle complex data calculations (like flight durations and arrival times) on the front end, while seamlessly integrating with Salesforce Agentforce to render rich, raw HTML responses directly in the UI.

## Key Features
* **Flight Details Management:** Dynamically calculates and formats flight durations (e.g., converting minutes to "X hr Y min") and arrival times based on departure data and timezone logic.
* **Agentforce HTML Rendering:** Utilizes a custom `htmlOutputContainer` to safely and cleanly render raw HTML output generated by an AI Agent directly into the Lightning interface.
* **Apex Data Structures:** Includes Apex classes (`Flight.cls`, `HtmlTestAgent.cls`) equipped with `@InvocableMethod` and `@AuraEnabled` annotations to pass data seamlessly between the backend, the AI agent, and the front-end LWC.

## Technologies Used
* Salesforce Lightning Web Components (LWC)
* JavaScript / HTML
* Apex (Salesforce Backend)
* Salesforce Agentforce / AI Integration

## Development Setup (Salesforce DX)
This project was built using source-driven development with Salesforce DX. If you want to deploy and test this code in your own environment, it is recommended to use a Scratch Org:

1. **Clone the repository:**
   `git clone https://github.com/igge88/MeetingBriefingLWC.git`
2. **Navigate to the directory:**
   `cd MeetingBriefingLWC`
3. **Create a new Scratch Org:**
   `sfdx force:org:create -s -f config/project-scratch-def.json -a MeetingBriefingOrg`
4. **Push the source code to your Scratch Org:**
   `sfdx force:source:push`
5. **Open the Scratch Org to test:**
   `sfdx force:org:open`

## How to Use
1. **Deploy to Salesforce:** If you are deploying to a Sandbox or Production environment instead of a Scratch Org, use the Salesforce CLI (`sfdx force:source:deploy`) or Visual Studio Code.
2. **Add to Lightning Page:** Open the Lightning App Builder in your Salesforce org and drag the custom LWC onto your desired record page or app home.
3. **Agent Integration:** Ensure your Agentforce topics and actions are configured to output to the `htmlOutputContainer` to see the rich HTML rendering in action.
